# Лабораторная работа №28. Веб-сервер на C#: список любимых игр с полным управлением 

**Студент:** Салалыкина Олеся || Дунюшкин Никита
**Курс:** 3 курс
**Группа:** ИСП-233

Это учебный проект на ASP.NET Core, представляющий собой REST API для управления списком видеоигр. В проекте реализовано хранение данных в оперативной памяти, фильтрация избранного и валидация входящих данных.

## Инструкция по запуску

```bash
dotnet run 
```

## Таблица всех маршрутов

|Метод  | Маршрут           | Описание            | Статус    |
|-------|-------------------|---------------------|-----------|
|GET	| /api/games        | Получить все игры   | 200       |
|GET	| /api/games/{id}   | Получить игру по id |	200 / 404 |
|POST	| /api/games	    | Добавить игру       | 201       |
|DELETE | /api/games/{id}   | Удалить игру        | 204 / 404 |

## Примеры curl-команд

**1. Получить все игры**
```bash
curl http://localhost:5000/api/games
```

**2. Получить игру по id**
```bash
curl http://localhost:5000/api/games/1
```

**3. Получить все игры**
```bash
curl -X POST http://localhost:5000/api/games \
     -H "Content-Type: application/json" \
     -d "{\"title\": \"Hades\", \"genre\": \"Roguelike\", \"releaseYear\": 2020, \"isFavourite\": true}"
```

**4. Удаление игру**
```bash
curl -X DELETE http://localhost:5000/api/games/1
```
